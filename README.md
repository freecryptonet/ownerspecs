# ownerspecs.com

Vehicle specification & owner-manual reference — fluids and capacities, maintenance schedules, torque specs, bulbs, fuses, tire data and service procedures, organized by model generation.

🔗 **Live:** https://ownerspecs.com

## What it does
- Owner-manual / FSM data the big spec sites miss (fluids, torque, bulbs, fuses, maintenance intervals)
- Organized by generation (e.g. `/2016-2021-honda-civic/oil-capacity`)
- Every spec is cross-verified against at least two independent sources, tracked in the data model
- Hundreds of generations and trims, growing

## Stack
Next.js · TypeScript · MariaDB (source-tracked schema) · deployed on a Linux VPS

Designed, built, and maintained by me.
